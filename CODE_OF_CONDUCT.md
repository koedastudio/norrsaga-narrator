# Code of Conduct

Be kind and stay on topic.

- Assume good faith. Critique code and ideas, never people.
- No harassment, personal attacks, discrimination or trolling, anywhere in the
  project.
- Maintainers may edit or remove content that breaks these rules and block
  contributors who keep breaking them.

Report problems through [GitHub](https://github.com/koedastudio) or, if public
contact is not appropriate, via
[private reporting](https://github.com/koedastudio/norrsaga-narrator/security/advisories/new).
Reports are handled confidentially.
